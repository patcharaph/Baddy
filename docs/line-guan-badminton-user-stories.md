## Epic 1: Guan & Membership (ก๊วนและสมาชิก)

### US-1.1 — Create a guan (สร้างก๊วน) → FR-1
**As a** หัวหน้าก๊วน **I want** สร้างก๊วนและได้ลิงก์เชิญ LINE **So that** ชวนสมาชิกเข้ามาได้ทันที
- สร้างก๊วนได้ (ชื่อ, สนามประจำ, เรตค่าคอร์ทตั้งต้น)
- ระบบสร้างลิงก์เชิญ LINE ให้แชร์ได้
- ผู้สร้างเป็น organizer โดยอัตโนมัติ

### US-1.2 — Join a guan (เข้าร่วมก๊วน) → FR-1, FR-9
**As a** ผู้เล่น **I want** กดลิงก์แล้วเข้าร่วมก๊วนด้วยบัญชี LINE **So that** ไม่ต้องสมัครเว็บใหม่
- กดลิงก์แล้วเข้าร่วมได้ด้วย LINE Login
- โปรไฟล์ผูกกับตัวผู้เล่น (portable) ใช้ข้ามก๊วนได้
- ถ้าเคยมีโปรไฟล์แล้ว ระบบผูกก๊วนใหม่กับโปรไฟล์เดิม

## Epic 2: Session & Join (รอบเล่นและการเข้าร่วม)

### US-2.1 — Create a session (สร้างรอบเล่น) → FR-2
**As a** หัวหน้าก๊วน **I want** เปิดรอบเล่น กำหนดเวลา/สนาม/คอร์ท/โควตา/เรต **So that** สมาชิกเข้าร่วมได้
- กำหนดวัน เวลา สนาม จำนวนคอร์ท เรตค่าคอร์ท และโควตาผู้เล่น
- เปิดรอบแล้วระบบสร้างลิงก์/แจ้งในก๊วนได้

### US-2.2 — RSVP in advance (จองล่วงหน้า) → FR-3
**As a** ผู้เล่น **I want** กดจองล่วงหน้า **So that** มั่นใจว่ามีที่
- กดเข้าร่วมล่วงหน้าได้ และเห็นสถานะ (ยืนยัน/waitlist)
- เมื่อเต็มโควตา เข้า waitlist ตามลำดับ

### US-2.3 — Walk-in check-in (เช็คอินหน้างาน) → FR-3
**As a** ผู้เล่น **I want** เช็คอินตอนถึงสนาม **So that** เข้าคิวเล่นได้แม้ไม่ได้จอง
- เช็คอินหน้างานได้ ระบบบันทึกเวลาเข้าสำหรับใช้หารเงิน
- ถ้าเต็ม เข้า waitlist

### US-2.4 — Waitlist auto-promote (เลื่อน waitlist อัตโนมัติ) → FR-3
**As a** ผู้เล่นใน waitlist **I want** ถูกเลื่อนขึ้นเมื่อมีที่ว่าง **So that** ไม่พลาดคิว
- เมื่อมีคนออก/ยกเลิก คนถัดไปใน waitlist เลื่อนขึ้นและได้รับแจ้งเตือน

### US-2.5 — Check out / leave early (เช็คเอาท์/กลับก่อน) → FR-7
**As a** ผู้เล่น **I want** แจ้งว่ากลับแล้ว **So that** ไม่ถูกคิดค่าคอร์ท/ค่าลูกช่วงที่ไม่อยู่
- กดเช็คเอาท์ได้ ระบบบันทึกเวลาออกเพื่อใช้หารเงิน

## Epic 3: Queue & Matches (คิวและแมตช์)

### US-3.1 — Auto fair queue (คิวหมุนเวียนยุติธรรม) → FR-4
**As a** หัวหน้าก๊วน **I want** ให้ระบบสุ่มจัด 4 คนลงคอร์ทอย่างยุติธรรม **So that** ไม่ต้องจำเองว่าใครควรได้ลง
- ระบบเลือกผู้เล่นลงคอร์ทโดยให้คนพักนาน/เล่นน้อยได้ลงก่อน
- รองรับหลายคอร์ทพร้อมกัน

### US-3.2 — Manual arrange (จัดเอง) → FR-4
**As a** หัวหน้าก๊วน **I want** ปรับตัวผู้เล่นในแมตช์เอง **So that** จัดตามฝีมือ/ตามที่เห็นควรได้
- ลาก/สลับผู้เล่นในคอร์ทได้ก่อนเริ่มแมตช์
- เห็นระดับฝีมือของผู้เล่นประกอบการจัด

### US-3.3 — Live queue board (ดูคิว real-time) → FR-5
**As a** ผู้เล่น **I want** ดูว่าเมื่อไรถึงคิวฉัน ลงคอร์ทไหน คู่กับใคร **So that** ไม่ต้องถามหัวหน้า
- เห็นคิวตัวเอง คอร์ท และคู่/คู่แข่ง อัปเดตทันที
- เห็นคิวถัดไปของตัวเอง

## Epic 4: Money (เงิน)

### US-4.1 — Log shuttle real-time (บันทึกลูก real-time) → FR-6
**As a** หัวหน้าก๊วน **I want** กด +1 เมื่อเปิดลูกใหม่ **So that** นับลูกสำหรับโหมดรายเกม/หารเท่ากันได้แม่น
- กด +1 ได้ระหว่างเล่น ระบบติดเวลาและผูกกับแมตช์ให้
- เผื่อกรอกจำนวนลูกย้อนหลังได้ถ้าลืมกด
- ใช้เฉพาะโหมดรายเกมและหารเท่ากัน (โหมดบุฟเฟ่ต์ไม่ต้องนับลูก)

### US-4.2 — Choose split mode (เลือกวิธีหารเงิน) → FR-7
**As a** หัวหน้าก๊วน **I want** เลือกวิธีหารเงินต่อรอบได้ 3 แบบ **So that** ตรงกับสไตล์ก๊วนของฉัน
- เลือกได้: บุฟเฟ่ต์เหมาจ่าย / รายเกม / หารเท่ากันตอนเลิก
- บุฟเฟ่ต์: ตั้งเรตต่อคน (รองรับเรตผู้หญิงแยก) ค่าลูกรวมในเรต
- ระบบใช้สูตรตามโหมดที่เลือกโดยอัตโนมัติ

### US-4.3 — Per-game billing (คิดค่าลูกรายเกม) → FR-7
**As a** ผู้เล่น **I want** จ่ายค่าลูกตามจำนวนเกมที่ฉันลงเล่น **So that** คนเล่นน้อยจ่ายน้อย ยุติธรรม
- ค่าลูก = จำนวนเกมที่ลง × เรตต่อเกม (นับเกมจากระบบจัดคิว)
- กฎลูกเกิน: ลูกที่เกินโควตาในแมตช์ หารเพิ่มเฉพาะ 4 คนในแมตช์นั้น
- แสดงที่มาของยอด (ลงกี่เกม + ลูกเกินกี่ลูก) ให้ตรวจได้

### US-4.4 — Settle up with PromptPay (เคลียร์เงิน) → FR-8
**As a** ผู้เล่น **I want** เห็น QR พร้อมเพย์และยอดของฉัน **So that** โอนจ่ายจบในที่เดียว
- แสดง QR พร้อมเพย์ของก๊วน + ยอดที่ต้องจ่าย
- หัวหน้า/ผู้เล่นติ๊กสถานะจ่าย/ยังไม่จ่ายได้
- ไม่มีการโอนเงินผ่านระบบ (คำนวณ+ติดตามสถานะเท่านั้น)

## Epic 5: Player Profile (โปรไฟล์ผู้เล่น — B-seed)

### US-5.1 — Skill level (ระดับฝีมือ) → FR-9
**As a** ผู้เล่น/หัวหน้า **I want** ระบุระดับฝีมือของผู้เล่น **So that** ใช้จัดตัวและต่อยอด auto ได้
- ตั้งระดับฝีมือ (มือ) ต่อผู้เล่นได้
- ⚠️ ASSUMPTION: สเกลระดับฝีมือยังต้องยืนยัน

### US-5.2 — Portable profile & basic stats (โปรไฟล์พกพา) → FR-9
**As a** ผู้เล่น **I want** มีโปรไฟล์ของตัวเองที่ใช้ข้ามก๊วน **So that** ประวัติไม่หายเมื่อเปลี่ยนก๊วน
- โปรไฟล์ผูกกับตัวผู้เล่น ไม่ผูกกับก๊วนเดียว
- เก็บสถิติพื้นฐาน เช่น จำนวนครั้งที่มา/จำนวนเกม
